# Web 工具导航

基于 Vue 3 + Vite + Tailwind CSS 的在线工具集合。

## 功能

- 计算器
- 工具箱
- 待办清单
- JSON 对比
- 天气
- 倒计时
- 阅读器
- 礼物书
- 网易云音乐
- 音乐播放器
- 国际象棋
- 五子棋
- 贪吃蛇

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
npm run preview
```

## 部署

推送到 `main` 分支后，GitHub Actions 自动构建并部署到 GitHub Pages：

https://xiaokang1993.github.io/web-tools/
